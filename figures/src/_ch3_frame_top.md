# วิธีการดำเนินโครงงาน

โครงงานนี้มีชื่อว่า "เว็บแอปพลิเคชันสื่อการเรียนรู้การเขียนโปรแกรม Python สำหรับผู้เริ่มต้น" จัดอยู่ในประเภทอื่น ๆ (เว็บแอปพลิเคชันสื่อการเรียนรู้) ระเบียบวิธีดำเนินงานประกอบด้วยการวิเคราะห์ความต้องการอย่างครอบคลุมจากการศึกษาอุปสรรคของผู้เริ่มต้นเรียนเขียนโปรแกรมและทฤษฎีการเรียนรู้ที่เกี่ยวข้อง ตามด้วยขั้นตอนการออกแบบและพัฒนาระบบเพื่อสร้างนวัตกรรมที่ตรงตามข้อกำหนดที่ระบุไว้ มีการทดสอบระบบอย่างเป็นระบบระหว่างการพัฒนา และการเก็บรวบรวมข้อมูลการประเมินผลหลังการพัฒนาด้วยแบบทดสอบประสิทธิภาพและแบบสอบถามความพึงพอใจ เพื่อเป็นกรอบสำหรับการเพิ่มประสิทธิภาพระบบในอนาคต โดยขั้นตอนการดำเนินโครงงานทั้งหมดสรุปดังภาพที่ 3.1

## 1. ขอบเขตการศึกษา

### 1.1 ขอบเขตโครงงาน

เว็บแอปพลิเคชันสื่อการเรียนรู้การเขียนโปรแกรม Python สำหรับผู้เริ่มต้น เป็นเว็บแอปพลิเคชันที่ทำงานได้ครบถ้วนในเบราว์เซอร์โดยไม่ต้องติดตั้งซอฟต์แวร์ ประกอบด้วยฟังก์ชันหลัก 5 ด้าน ได้แก่ ระบบบทเรียนแบบภารกิจ (ด่านปฐมนิเทศ 1 ด่าน บทเรียน 15 ด่านใน 5 Module มินิโปรเจกต์ 4 ชิ้น และ Capstone Project 1 ด่าน รวม 21 ด่าน) ระบบ Code Editor พร้อมการรันโค้ดด้วย Skulpt ระบบ Error Message ภาษาไทยและคำใบ้ 3 ระดับ ระบบติดตามความก้าวหน้าอัตโนมัติ และระบบบัญชีผู้ใช้กับการซิงก์ข้อมูลข้ามอุปกรณ์แบบไม่บังคับด้วย Firebase โดยรองรับผู้ใช้ 3 ระดับ คือ ผู้เยี่ยมชม สมาชิก และผู้ดูแลระบบ รายละเอียดขอบเขตทั้งหมดเป็นไปตามที่กำหนดไว้ในบทที่ 1

### 1.2 ขอบเขตกลุ่มเป้าหมาย

**1.2.1 ประชากร**

นักศึกษาวิทยาลัยเทคโนโลยีไออาร์พีซีที่ไม่เคยเขียนโปรแกรมมาก่อน

**1.2.2 กลุ่มตัวอย่าง**

นักศึกษาวิทยาลัยเทคโนโลยีไออาร์พีซี จำนวนประมาณ 50 คน ได้มาโดยการเลือกแบบเจาะจง (Purposive Sampling) โดยเลือกผู้ที่ไม่มีประสบการณ์การเขียนโปรแกรมมาก่อน

### 1.3 ระยะเวลาในการดำเนินงาน

8 พฤษภาคม 2569 ถึง 28 กุมภาพันธ์ 2570

### 1.4 งบประมาณ

งบประมาณในการดำเนินงานรวม 1,817 บาท ประกอบด้วย ค่ากระดาษ A4 จำนวน 3 รีม (315 บาท) ค่าสมัครใช้งาน Claude Pro สำหรับเป็นผู้ช่วยพัฒนาระบบ จำนวน 2 เดือน (1,302 บาท) และค่าเข้าเล่มรายงาน จำนวน 2 เล่ม (200 บาท)

## 3. ขั้นตอนการดำเนินงาน

### 3.1 กระบวนการเตรียมข้อมูล

คณะผู้จัดทำเตรียมข้อมูลก่อนการพัฒนาระบบสี่ส่วน ส่วนแรกคือการศึกษาแนวคิด ทฤษฎีการเรียนรู้ และงานวิจัยที่เกี่ยวข้องทั้งในและต่างประเทศรวม 6 ฉบับ ตามที่เรียบเรียงไว้ในบทที่ 2 เพื่อใช้เป็นกรอบในการออกแบบระบบ ส่วนที่สองคือการวิเคราะห์อุปสรรคหลักของผู้เริ่มต้นสามประการ (ความสับสนเมื่อพบ Error ความกลัวการทำผิด และภาวะติดกับดักบทเรียน) เพื่อแปลงเป็นข้อกำหนดของระบบ ส่วนที่สามคือการทดสอบยืนยันความสามารถของตัวแปลภาษา Skulpt ก่อนพัฒนาจริง (Smoke Test) ครบ 19 รายการ ครอบคลุมตั้งแต่ f-string การรับข้อมูลด้วย input() ไปจนถึงชนิดของข้อผิดพลาดที่ระบบต้องดักจับ เพื่อยืนยันว่าขอบเขตเนื้อหาที่วางไว้ทำงานได้จริงบนเทคโนโลยีที่เลือก และส่วนที่สี่คือการกำหนดขอบเขตเนื้อหาภาษา Python เฉพาะแนวคิดพื้นฐานที่จำเป็น 10 กลุ่ม ตั้งแต่ print() จนถึงการนิยามฟังก์ชัน

### 3.2 วิเคราะห์ข้อมูล

**3.2.1 สถิติที่ใช้ในการวิเคราะห์ข้อมูล**

การวิเคราะห์ข้อมูลความพึงพอใจของกลุ่มตัวอย่างใช้สถิติพื้นฐาน ได้แก่ ค่าเฉลี่ย (Mean) และส่วนเบี่ยงเบนมาตรฐาน (Standard Deviation) โดยรายละเอียดของสูตรและเกณฑ์การแปลผลอธิบายไว้ในข้อ 5

**3.2.2 เกี่ยวกับระบบที่พัฒนา**

การวิเคราะห์คุณภาพของระบบใช้การทดสอบแบบกล่องดำ (Black-box Testing) ซึ่งตรวจสอบความถูกต้องของผลลัพธ์จากมุมมองผู้ใช้โดยไม่พิจารณาโครงสร้างโค้ดภายใน ร่วมกับชุดทดสอบอัตโนมัติที่พัฒนาขึ้นเอง 3 ชุด ได้แก่ ชุดทดสอบความถูกต้องของเกณฑ์การผ่านทุกด่าน ชุดทดสอบเชิงปรปักษ์ (Adversarial Testing) ที่จำลองความผิดพลาดจริงของผู้เริ่มต้น และชุดทดสอบกรณีขอบเขตของระบบ รายละเอียดผลการทดสอบสรุปในหัวข้อ 3.6 และข้อ 6

### 3.3 ออกแบบโครงงาน

หัวข้อนี้นำเสนอผลการออกแบบระบบทั้งหมดของโครงงาน ซึ่งแปลงกรอบทฤษฎีที่ศึกษาไว้ในบทที่ 2 มาเป็นข้อกำหนดที่สร้างได้จริง แบ่งเป็นสามกลุ่ม กลุ่มแรกคือการออกแบบหลักสูตรและบทเรียน (หัวข้อ 3.3.1 ถึง 3.3.6) กลุ่มที่สองคือการออกแบบบทบาทผู้ใช้ ฐานข้อมูล และการซิงก์ข้อมูล (หัวข้อ 3.3.7 ถึง 3.3.12) และกลุ่มที่สามคือการออกแบบสถาปัตยกรรมระบบและส่วนติดต่อผู้ใช้ (หัวข้อ 3.3.13 ถึง 3.3.14)
